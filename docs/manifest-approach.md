# Manifest-Based Image Retrieval

## Overview

This project now uses a manifest-based approach for retrieving images from Vercel Blob storage instead of making direct API calls to list blobs. This approach provides better performance and reduces API calls.

## How It Works

### 1. Manifest File
- Location: `data/manifest.json`
- Contains: Array of all image URLs from Vercel Blob storage
- Generated by: `scripts/build-manifest.mjs`

### 2. Utility Functions
- Location: `lib/manifest-utils.ts`
- Functions:
  - `getImagesFromManifest(pathPattern)`: Get all images matching a path pattern
  - `getFilenamesFromManifest(pathPattern)`: Get just filenames matching a path pattern
  - `fileExistsInManifest(filePath)`: Check if a specific file exists
  - `getFileUrl(filePath)`: Get the full URL for a specific file

### 3. API Endpoints
- `/api/images`: Lists images for a product/directory combination
- `/api/media`: Lists media files for a specific path

## Usage

### API Usage
```typescript
// Get images for a product
fetch('/api/images?productId=roller&directory=cordless/color')
  .then(res => res.json())
  .then(files => {
    // files is an array of filenames
    console.log(files);
  });
```

### Direct Manifest Usage
```typescript
import { getFilenamesFromManifest } from '@/lib/manifest-utils';

// Get all color images for roller cordless
const colorFiles = getFilenamesFromManifest('blinds/roller/cordless/color/');
console.log(colorFiles);
```

## Benefits

1. **Performance**: No API calls to Vercel Blob for listing files
2. **Reliability**: Works even if Vercel Blob API is temporarily unavailable
3. **Speed**: Instant file listing from local manifest
4. **Cost**: Reduces API calls to Vercel Blob storage

## Updating the Manifest

To update the manifest with new images:

1. Run the build script:
   ```bash
   node scripts/build-manifest.mjs
   ```

2. The script will:
   - Connect to Vercel Blob storage
   - List all files with the `blinds/` prefix
   - Save the URLs to `data/manifest.json`

## File Structure

```
data/
  manifest.json          # All image URLs
lib/
  manifest-utils.ts      # Utility functions
  blob-storage.ts        # Upload/delete functions only
app/
  api/
    images/route.ts      # Uses manifest for listing
    media/route.ts       # Uses manifest for listing
scripts/
  build-manifest.mjs     # Generates manifest.json
```

## Migration Notes

- Old approach used `listBlobs()` from `@vercel/blob`
- New approach uses local manifest file
- Upload and delete operations still use Vercel Blob API
- All existing components continue to work without changes
